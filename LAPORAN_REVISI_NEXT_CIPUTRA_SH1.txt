LAPORAN REVISI NEXT CIPUTRA SH-1
Fokus: baca teks revisi dan terapkan tanpa redesign total.

1. Ringkasan perubahan
- Desain utama, layout dashboard, warna, sidebar, tabel, grafik, login, pengajuan user, temuan, jawaban, upload foto, print PDF, database, dan API utama tetap dipertahankan.
- Logo Ciputra dibuat transparan di landing/navbar, sidebar, loading spinner, dan header form pengajuan.
- Admin mendapat menu baru Master Proyek untuk tambah/edit/nonaktifkan/hapus aman proyek.
- Dropdown proyek pada form pengajuan user dan form internal mengambil data proyek aktif dari database.
- No KQI otomatis memakai kode proyek, contoh kode BSD menjadi KQI-BSD-YYYYMMDD-001.
- Emoji/stiker yang ramai diganti dengan icon minimalis berbasis CSS ringan.
- Audit Logs admin ditingkatkan dengan login tracking, hapus log, ban IP, ban username/user, daftar banned, dan unban.
- Login mengecek banned_access sebelum memproses password.
- Footer landing page dibersihkan: daftar proyek di footer dihapus, bagian Dr. Ciputra diberi animasi scroll IntersectionObserver, dan Tentang Sistem + copyright disatukan.

4. Perubahan database
- Tabel proyek ditambah kolom kode_proyek dan site_area.
- Tabel audit_logs ditambah username_attempt, role_attempt, status, risk_level, notes, failed_attempts.
- Tabel banned_access ditambahkan untuk ban IP/user.
- Migration dibuat aman tanpa DROP TABLE untuk database lama.

5. Fitur Master Proyek
- Admin bisa melihat daftar proyek.
- Admin bisa menambahkan proyek baru.
- Admin bisa mengedit proyek.
- Admin bisa aktif/nonaktifkan proyek.
- Admin bisa hapus proyek jika belum dipakai data.
- Jika proyek sudah dipakai temuan/pengaduan, sistem menonaktifkan proyek agar data lama aman.

6. Fitur Audit Logs & Ban
- Tampil username/email percobaan login.
- Tampil role attempt.
- Tampil IP address dan user agent/device.
- Tampil status login sukses/gagal/blocked.
- Tampil jumlah percobaan gagal.
- Tampil risk level normal/mencurigakan/blocked.
- Admin bisa hapus log.
- Admin bisa ban IP.
- Admin bisa ban username/user.
- Admin bisa melihat daftar banned.
- Admin bisa unban.
- Login dari IP/user banned ditolak dengan pesan umum.

7. Footer dan logo
- Background putih pada logo dihilangkan dari CSS.
- Logo tampil transparan, object-fit contain, dan tetap proporsional.
- Footer tidak lagi menampilkan daftar proyek Ciputra.
- Foto bapak.png muncul saat scroll dengan fade, scale, slide, dan glow halus.
- Teks Dr. Ciputra muncul setelah animasi foto.
- Tentang Sistem dan copyright disatukan dalam section bawah footer.

- Import / jalankan update_ciputra_sh_v_next.sql.
- Jangan import ulang database_install_full.sql jika ingin mempertahankan data lama.
- Setelah migration, login admin lalu cek Master Proyek dan Audit Logs.

10. Catatan jujur

- Saya sudah melakukan PHP syntax check dan JavaScript syntax check.
