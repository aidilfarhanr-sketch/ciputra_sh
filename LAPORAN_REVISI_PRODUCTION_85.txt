6. Security yang ditambahkan
- CSRF token penuh untuk POST/PUT/PATCH/DELETE.
- Token disimpan di session dan dikirim ke frontend melalui meta tag.
- Session cookie HttpOnly, SameSite=Lax, Secure saat HTTPS.
- session_regenerate_id setelah login.
- Logout memakai POST dan session destroy lebih aman.
- Security headers: X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, CSP dasar.
- Error teknis disembunyikan dari user dan dicatat ke logs/app.log.
- Upload diperketat: validasi MIME asli, ekstensi, jumlah file, total ukuran, nama random aman, block PHP/JS/HTML/SVG di uploads.

7. Rate limiting yang ditambahkan
- Login tetap 5 gagal per 15 menit per email/IP.
- Form keluhan publik dibatasi 3 submit/10 menit dan 10 submit/hari per IP+user-agent.
- Upload dibatasi maksimal 8 file/request, 6MB/file, 24MB total/request, dan rate limit upload.
- Endpoint penting diberi require_rate_limit: create user, update user, reset password, create temuan QC, workflow, save answer, bulk import, delete.
